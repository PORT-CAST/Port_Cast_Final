# PORTCAST

**Port × Forecast — 기상조건·기상특보에 따른 부산항 터미널 체류시간 분석 및 운영 의사결정 지원**

> 특보가 뜨면, 부두의 시간은 얼마나 길어질까?

PORTCAST는 부산항 북항·신항의 선박 기항 기록에 작업량, 기상 관측, 기상특보 자료를 연결해 체류시간의 차이를 분석하는 프로젝트입니다. 기상 구간과 특보 노출 여부에 따른 집단 비교를 수행하고, 항만·터미널별 다중회귀모형으로 선박 규모·작업량·시기 차이를 함께 고려합니다.

분석 결과는 Streamlit 기반 대시보드와 AI 요약으로 전달해 터미널 운영 상황을 이해하고 판단하는 데 활용합니다. 현재 분석은 **체류기간 전체의 관측 기상을 이용한 사후 조건부 분석**이며, 입항 시점의 실시간 미래예측이나 기상의 인과효과 추정과는 구분합니다.

## 1. 프로젝트 배경과 목적

선박 체류시간은 선사·화주의 비용, 운송 일정, 항만 혼잡과 연결됩니다. 그러나 체류시간이 길어진 이유를 기상만으로 설명하기는 어렵습니다. 선박 규모와 작업량, 터미널의 운영 특성, 계절·연도 차이도 함께 반영되기 때문입니다.

이 프로젝트는 다음 질문을 다룹니다.

- 풍속·돌풍·파고·시정 조건에 따라 체류시간은 어떻게 달라지는가?
- 체류 중 기상특보에 노출된 선박과 노출되지 않은 선박의 차이는 얼마인가?
- 규모·작업량·기상·시기를 고려한 후에도 항만·터미널별 차이가 남는가?
- 이러한 차이와 불확실성을 대시보드에서 어떻게 전달할 것인가?

## 3. 분석 흐름

```text
선박·작업량·기상·특보 자료 수집
    ↓
날짜·식별자·숫자형 정리 및 자료 결합
    ↓
기항별 체류시간·체류 구간 기상 대표값·특보 노출 계산
    ↓
EDA 및 선박 규모·작업량 조건을 제한한 KPI 비교
    ↓
학습·검증 분리 → 변수 검토 → OLS 후보 모형 적합
    ↓
잔차·공선성·집단별 오차·KPI 불확실성 진단
    ↓
대표 모형 선정 → 대시보드 시각화·시나리오·AI 요약
```

기상값은 같은 항만의 체류 구간 관측자료를 연결해 집계합니다. 특보는 겹치는 구간을 정리한 뒤 다음 원리로 노출시간을 계산합니다.

```text
특보 구간별 겹침 = max(0, min(출항시각, 특보종료) − max(접안시각, 특보발효))
특보노출시간 = 중복을 제거한 겹침 시간의 합
특보유무 = 특보노출시간이 0보다 크면 1, 아니면 0
```

## 4. 핵심 KPI

### KPI1: 기상조건별 체류시간 차이

같은 터미널 안에서 선박 규모·작업량 범위를 제한하고, 기상 기준 구간과 비교 구간의 **체류시간 중앙값 차이**를 구합니다.

| 기상 지표 | 기준 구간 | 비교 구간 |
|---|---|---|
| 풍속 중앙값 | 0~2m/s 미만 | 4m/s 이상 |
| 최대순간풍속 최댓값 | 5m/s 미만 | 8m/s 이상 |
| 유의파고 최댓값 | 0.5m 미만 | 2m 이상 |
| 시정 최솟값 | 30km 이상 | 5km 미만 |

```text
KPI1 = 비교 구간 체류시간 중앙값 − 기준 구간 체류시간 중앙값
```

### KPI2: 특보 노출별 체류시간 차이

같은 조건 제한 표본에서 체류 중 특보 노출 여부에 따른 체류시간 중앙값을 비교합니다.

```text
KPI2 = 특보 노출 집단 체류시간 중앙값 − 비노출 집단 체류시간 중앙값
```

조건 제한은 북항 `5,000 ≤ GT < 10,000`, 작업량 `400~600`, 신항 `100,000 ≤ GT < 150,000`, 작업량 `2,000~2,500`을 사용합니다. 비교는 같은 항만 안의 터미널을 대상으로 합니다.

두 KPI의 양수는 더 긴 체류, 음수는 더 짧은 체류 방향을 뜻합니다. **KPI별 차이는 합산하지 않으며, 조건 제한만으로 인과효과가 식별되는 것은 아닙니다.**

## 5. 다중회귀분석

집단별 중앙값 비교를 보완하기 위해 항만·터미널을 각각 구분하는 OLS 모형을 적합합니다. 구분별 절편뿐 아니라 총톤수·작업량·특보·기상과의 관계도 달라질 수 있도록 상호작용항을 포함합니다.

| 단계 | 추가하는 정보 |
|---|---|
| M1 | 항만 또는 터미널 구분 |
| M2 | 총톤수·총작업량과 구분별 상호작용 |
| M3 | 특보유무와 구분별 상호작용 |
| M4 | 기상변수 6개와 구분별 상호작용 |
| M4_time | M4 + 공통 월·요일 효과 + 연도추세 |
| M5 | M4를 확장해 규모·작업량 × 특보·기상 및 해당 관계의 구분별 차이 추가 |
| M5_time | M5 + 공통 월·요일 효과 + 연도추세 |

연도는 미래 검증연도의 별도 더미계수를 추정하는 방식 대신 **숫자형 연도추세**로 반영합니다. 변환·중심화·표준화 기준은 해당 모형의 학습자료 기준을 따릅니다.

모형 선택은 학습 R²만으로 결정하지 않습니다. 같은 검증 행의 MAE·RMSE, 잔차 패턴, 집단별 편향, 공선성, 특보 시나리오의 불확실성, 계수 수를 함께 검토합니다. 결측치 다중대치(MICE)는 별도 탐색·민감도 분석으로 다뤘으며, 아래 대표 회귀 결과는 완전사례 분석 기준입니다.

### 대표 모형과 검증 결과

두 분석 모두 **M4_time**을 대표 모형으로 선택했습니다.

| 분석 단위 | 계수 수(절편 포함) | 2024년 검증 MAE(h) | 2024년 검증 RMSE(h) |
|---|---:|---:|---:|
| 항만 | 38 | 3.113 | 4.279 |
| 터미널 | 78 | 3.0167 | 4.1923 |

항만 모형의 전체자료 재적합 R² `0.7352`는 설명용 적합도입니다. 위 표의 검증오차와 같은 종류의 지표가 아니며, 재적합 결과를 검증 성능으로 제시하지 않습니다.

### 회귀모형 기반 특보 시나리오

다른 입력은 고정하고 특보유무만 바꾼 **조건부 예측 평균 차이**를 계산합니다.

```text
특보 시나리오 예상 차이 = 예측 체류시간(특보=1) − 예측 체류시간(특보=0)
```

| 항만 | 예상 차이(h) | 95% 근사 신뢰구간(h) |
|---|---:|---|
| 북항 | +0.671 | 0.015~1.326 |
| 신항 | +0.735 | 0.294~1.177 |

위 항만 값은 전체자료 재적합과 선박·14일 시간블록 이중군집 공분산 기준입니다. 터미널 모형에서는 날짜 기반 HAC 신뢰구간을 사용하며, BPT_S·HPNT·BNCT는 약 +1시간의 양의 차이에 대한 근거가 나타났습니다. PNIT·BPTC_G·PNC는 증가 여부가 불확실합니다. 이를 차이가 없다는 증거로 해석하지 않습니다.

현재 대표 모형은 특보와 규모·작업량·기상 간 추가 곱항을 포함하지 않으므로 **같은 항만·터미널 안의 특보 ON/OFF 차이는 일정**합니다. 이 차이는 앞의 중앙값 기반 KPI1·KPI2와 계산 방식이 다른 보완 지표입니다.

## 6. 대시보드와 기술 구성

대시보드는 터미널·기상조건별 결과 조회, 그래프와 KPI 확인, 특보 시나리오 비교, AI 요약을 통해 분석 결과를 전달하는 구조입니다. 전체 예상 체류시간과 기준 대비 시나리오 차이를 분리하고, 불확실성을 함께 안내합니다.

| 영역 | 사용 기술 | 역할 |
|---|---|---|
| 분석 환경 | Python, Jupyter Notebook | 전처리·EDA·회귀분석 |
| 데이터 처리 | pandas, NumPy, openpyxl | CSV·Excel 처리, 날짜 결합, 집계·수치 계산 |
| 통계 분석 | statsmodels, SciPy | OLS, VIF, 잔차 진단, 강건 추론·신뢰구간 |
| 시각화 | Matplotlib, Seaborn, Plotly | 탐색·진단 그래프 및 대시보드 시각화 |
| 대시보드 | Streamlit, Streamlit Cloud | 분석 결과 제공 및 배포 환경 |
| AI 요약 | Gemini API | 분석 결과의 자연어 요약 연계 |
| 별도 탐색 | scikit-learn | 결측치 처리 등 보조 실험 |

이 문서는 발표자료를 바탕으로 작성한 **프로젝트 개요**입니다. 실행 명령, 의존성 버전, 환경변수는 실제 대시보드 저장소의 실행 파일·환경 설정에 맞춰 관리합니다. 원본 데이터와 API 키의 공개 범위는 각각의 이용 조건·관리 기준을 확인해야 합니다.

## 7. 주요 관찰과 해석 범위

- 작업량은 총톤수보다 체류시간과 더 강한 상관을 보여, 규모뿐 아니라 작업량을 맞춘 비교가 필요했습니다.
- 강한 돌풍·높은 파고 구간에서 체류시간이 더 긴 사례가 나타났지만, 일부 구간은 표본이 적고 같은 기상 사례에 기록이 몰려 있습니다.
- 특보 노출 집단의 단순 체류시간 차이는 규모·작업량 범위를 제한하면 줄어들었습니다.
- 회귀모형에 기상·시간 통제를 추가하면 검증오차가 개선됐지만, 장기 체류의 과소예측과 항만·터미널별 편향은 남았습니다.

### 남은 한계

1. **관측 기회의 차이:** 체류가 길수록 특보나 강한 기상을 만날 기회도 커집니다. 체류 중 집계값과 체류시간의 관계를 인과효과로 단정할 수 없습니다.
2. **예측 시점의 제약:** 체류기간 전체 기상은 입항 시점에 알 수 없습니다. 현재 검증을 입항 시점의 실시간 예측 성능으로 해석하지 않습니다.
3. **잔차 가정의 한계:** 이분산성·오른쪽 꼬리·시간 및 집단별 의존성이 남습니다. 강건 표준오차는 추론을 보완하지만 잔차 문제 자체를 없애지는 않습니다.
4. **표본과 결측의 영향:** 분석별 제외 기준이 다르며, 완전사례 분석은 특정 기간·집단이 더 많이 제외되는 선택 편향 가능성이 있습니다.
5. **검증자료의 반복 사용:** 2024년 결과를 모형 선택에도 사용했습니다. 후속 기간이나 별도로 남긴 자료에서 추가 검증이 필요합니다.
6. **시나리오의 범위:** 특보 ON/OFF 차이는 인과적 지연시간이나 개별 선박의 확정 증가시간이 아닙니다. 점추정과 신뢰구간·불확실 판단을 함께 제시합니다.

후속 과제로는 고정 관측창·예보자료를 활용한 입력 구성, 장기 체류와 터미널 편향 개선, 신규 기간 검증을 검토할 수 있습니다.
